정적 QR 코드

주소나 텍스트를 정적 QR 코드 하나로 만들고 PNG·SVG로 저장하세요.

3단계 사용법

  1. 주소 또는 텍스트 종류를 선택하고 내용을 입력하세요.
  2. 출력 크기를 선택하고 QR을 생성하세요.
  3. PNG·SVG를 저장한 뒤 실제 스캔으로 확인하세요.

지원 기능과 제한

UTF-8 텍스트, PNG·SVG 저장과 인쇄용 문서를 지원합니다.

최대 UTF-8 500바이트. HTTP·HTTPS 주소에 사용자 인증정보를 넣을 수 없습니다. 일괄·동적 QR, 주소 단축, 스캔 통계는 없습니다.

문제가 생기면

빈 입력·URL 형식·UTF-8 바이트 수를 확인하세요. 스캔이 어려우면 여백을 유지하고 출력 크기를 늘리세요.

Turn a URL or text into one static QR code and save it as PNG or SVG.
