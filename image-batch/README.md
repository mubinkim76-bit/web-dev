# 이미지 규격 일괄팩 / Image batch studio

독립 프로젝트 `image-batch` · 버전 `0.2.3-independent.1` · 원본 v0.2.3 보존 추출.

Node 20 이상. `npm install` 없이 실행합니다. 이 폴더만 복사해도 동작하며, 다른 10개 프로젝트나 원본 저장소가 필요하지 않습니다.

```sh
npm start
npm test
npm run lint
npm run build
npm run preview
```

기본 로컬 포트는 4173입니다. 동시에 실행하면 각 프로젝트에 다른 `PORT`를 지정하세요. 첫 화면은 해당 도구이며 다른 도구 메뉴가 없습니다. 한국어/영어 전환 버튼 또는 `?lang=en`을 지원합니다. 브라우저 보안 때문에 HTML을 파일로 직접 여는 대신 HTTP 서버로 실행하세요.

정적 호스팅 배포 단위는 이 프로젝트의 `dist/` 하나입니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. 원본 전체 소스/QA/다른 프로젝트를 공개 업로드하지 마세요.

무료 비회원 정책: 정상 결과/내려받기는 무료이며 가입, 결제, 광고, OCR 서버, 운영 집계, 서버 저장을 연결하지 않습니다. 앱 입력은 현재 브라우저에서 처리합니다. 호스팅 사업자의 접근 로그/IP 처리에 관한 추가 보장은 하지 않습니다. 메모리 입력은 새로고침·언어 전환·탭 종료 시 사라집니다. 오목은 선택적 현재 판 저장이 예외입니다.

이 서비스의 기능·정확한 지원 한도·미구현 범위는 `SPEC.json`에 기록했습니다. 추출한 도구 모듈에서 기존 입력 한도를 유지합니다. 법적/회계/구조 적합성 판단을 제공하지 않습니다.

라이선스: `LICENSE.md`, `THIRD_PARTY_NOTICES.md`, 각 vendor/font의 전문을 확인하세요. `SOURCE-PROVENANCE.json`은 원본과 동일한 파일 및 분리용 변경을 기록합니다.

검증: `npm test`는 Node 엔진/DOM 계약 시험이며 실제 브라우저 통과를 뜻하지 않습니다. 기존 브라우저 시험 요약은 `SPEC.json` 및 `validation.json`에 있습니다. 대용량 브라우저 출력은 이 저장소에 포함하지 않습니다. 브라우저 재시험 방법은 `qa/README.md`를 확인하세요. 실물 모바일·물리 인쇄·운영 Cloudflare URL은 별도 검증 대상입니다.
