이미지 일괄 변환

사진 여러 장의 크기·형식·파일명을 바꾸고 개별 파일이나 ZIP으로 저장하세요.

3단계 사용법

  1. JPEG·PNG·정적 WebP 이미지를 추가하세요.
  2. 출력 크기·형식·파일명을 설정하세요.
  3. 미리보기와 결과를 확인한 뒤 내려받으세요.

지원 기능과 제한

최대 3개 출력 프리셋과 JSON 설정 가져오기·저장을 지원합니다.

데스크톱 최대 20장·100 MiB·이미지당 24 MP, 좁은 화면 최대 10장·40 MiB·12 MP. 출력 크기 16–4096px. HEIC·RAW·SVG·애니메이션은 지원하지 않습니다.

문제가 생기면

파일 형식·용량·픽셀 수를 확인하세요. 처리에 실패하면 해당 파일을 제외하거나 더 작은 이미지로 다시 시도하세요.

Resize, convert and rename multiple images, then save individual files or a ZIP.
