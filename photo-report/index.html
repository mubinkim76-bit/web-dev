사진 보고서

사진과 직접 입력한 설명을 A4 또는 Letter 보고서로 배치하고 PDF로 저장하세요.

3단계 사용법

  1. 사진을 추가하고 순서를 정하세요.
  2. 제목·설명·날짜와 페이지 배치를 입력하세요.
  3. 모든 페이지를 확인하고 PDF를 저장하세요.

지원 기능과 제한

페이지당 2·4·6장 배치와 파일명이 정확히 일치하는 설명 CSV를 지원합니다.

데스크톱 최대 30장·100 MiB·사진당 24 MP, 좁은 화면 최대 10장·40 MiB·12 MP. 설명은 300자까지. OCR·날짜 자동 추출은 없습니다.

문제가 생기면

사진 한도를 확인하세요. CSV 설명이 연결되지 않으면 파일명과 열 형식을 확인하고 다시 가져오세요.
