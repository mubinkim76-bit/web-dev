시간대와 회의 시간

여러 지역의 시각을 변환하고 가능한 회의 시간과 ICS 파일을 확인하세요.

3단계 사용법

  1. 기준 지역의 날짜·시각과 비교할 시간대를 입력하세요.
  2. 각 지역의 가능 시간과 회의 길이를 정하고 변환하세요.
  3. 겹치는 시간과 DST 안내를 확인하고 ICS를 저장하세요.

지원 기능과 제한

브라우저 Intl의 IANA 시간대 규칙과 UTC 기반 ICS를 사용합니다.

1–6개 시간대, 1970–2100년 날짜. 실제 일정·공휴일 조회, 캘린더 계정 연결과 자동 초대는 없습니다.

문제가 생기면

DST로 존재하지 않는 시각은 다른 시각을 선택하세요. 두 번 존재하는 시각은 UTC 후보 중 하나를 고르세요. 겹치는 시간이 없으면 가능 범위를 넓히세요.
