텍스트 정리와 글자 수

공백·빈 줄·중복 줄을 정리하고 글자 수와 UTF-8 크기를 확인하세요.

3단계 사용법

  1. 정리할 텍스트를 붙여 넣으세요.
  2. 필요한 정리 규칙과 순서를 선택하세요.
  3. 결과를 확인하고 TXT로 내려받으세요.

지원 기능과 제한

문자열 기반 치환, 글자·단어·줄 집계, 작업 취소와 원본 복원을 지원합니다.

UTF-8 1 MiB·입력창 실제 줄 2,000개까지. 문장 의미를 다시 쓰거나 문서 파일 형식을 변환하지 않습니다.

문제가 생기면

용량이나 줄 수 한도를 넘으면 텍스트를 나눠 처리하세요. 원치 않는 결과는 원본을 복원하고 규칙을 조정하세요.

Clean up whitespace, blank lines and duplicate lines; check character counts and UTF-8 size.
